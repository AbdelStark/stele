# Larger exponential product domains (Q25)

Research continuation of [the exponential study](cqis-exp.md), for Draft
RFC-0004 A2. This defines a candidate function family, not an admitted attention
configuration, canonical registry encoding or change to Accepted defaults.

## 1. Explicit split and complete domain

Parameters are integers B,F,E,k with 7<=B<=31, 0<=F<=30, 0<=E<=14,
1<=k<=16 and 0<=B-k<=15. The research field `split` is k. Its default 7
preserves the initial study; larger configurations must choose a valid split
explicitly. Boolean, out-of-range and incomplete metadata encodings reject.

Set Q=2^E. For -2^B<=t<=0, uniquely decompose u=-t=2^k h+l, 0<=l<2^k.
Let R(x)=floor(x+1/2) for nonnegative x and define

    H[h] = R(Q exp(-2^k h/2^F)),   0<=h<=2^(B-k),
    L[l] = R(Q exp(-l/2^F)),       0<=l<2^k,
    P_k(t) = floor(H[h] L[l]/Q).

The inclusive domain has 2^B+1 values. The last high index is valid only with
l=0; it is a real endpoint, not padding. The complete u bound must be enforced,
since separate h/l ranges otherwise admit values past the endpoint. P_k(0)=Q
and 0<=P_k(t)<=Q. All requested entries must certify; bounded precision failure
rejects the configuration. This is not a uniform separation theorem for all
parameter combinations.

Changing k changes the integer function. At B=14,F=10,E=12,t=-9152, k=7
gives 0 and k=6 gives 1; 1,239 of the 16,385 outputs differ. Therefore k must
be bound in the future definition/version/parameter identity. An implementation
cannot substitute a cheaper split while keeping the same identity. The research
metadata is now [B,F,E,k], not a canonical protocol byte format. Corrected D and
uncorrected P_k also remain distinct functions. P_k need not be monotone.

## 2. Certified large arguments and uniform error

Every exponential argument is rational in [0,2^31]. For requested width 2^-b,
if x>=b+1, exp(1)>2 proves 0<exp(-x)<2^-(b+1). The certificate returns
(lower,upper,precision)=(0,1,b+1), with strict width below 2^-b. It preserves
the positive real tail; an integer value of zero is returned only when the
rounded enclosure endpoints agree. Type/precision checks precede this shortcut.

For x<b+1, the original alternating Taylor and outward dyadic squaring method
applies. For b<=256, at most ten squarings suffice, so the existing 512-term
inner cap is sufficient for the interval width. The first successful precision
from 32,64,128,256 is retained and independently regenerated by validation.
The independent oracle uses positive Taylor/reciprocal bounds instead.

With a=exp(-2^k h/2^F) and b=exp(-l/2^F), the initial proof is unchanged:
|HL/Q-Qab|<=1, and flooring subtracts less than one. Thus

    -2 < P_k(t)-Q exp(t/2^F) <= 1.

Absolute error is strictly below two integer output units, uniformly over
every legal t and split. This is an absolute bound, not relative accuracy in
the tail, monotonicity, a model-fidelity bound or permission to clamp a score.

## 3. Storage, field obligations and cost

H has 2^(B-k)+1<=32,769 rows, L has 2^k<=65,536. With power-of-two padding,
each fits at most 65,536 rows; padding must remain excluded from membership.
The virtual function can have 2^31+1 inputs without materializing that domain.
Examples of actual rows (cardinalities, not benchmark results):

| B | k | H | L | Virtual domain |
|---|---|---|---|---|
| 22 | 7 | 32,769 | 128 | 4,194,305 |
| 22 | 11 | 2,049 | 2,048 | 4,194,305 |
| 23 | 12 | 2,049 | 4,096 | 8,388,609 |
| 31 | 16 | 32,769 | 65,536 | 2,147,483,649 |

The first two rows define different P_k functions. Generation/storage requires
O(2^(B-k)+2^k) rows, and one product evaluation uses two indexed memberships and
HL=QY+r with 0<=r<Q, plus index/sign/range consumers. This contributes two
membership terms to c_lu and the complete arithmetic to c_a; one-time generation
and public-table evaluation belong in T_misc. No measured constant moves.

For E<=14, HL<=Q^2 and QY+r<=Q^2+Q-1 satisfy the centered M31 half-bound.
These static product bounds do not certify the index relation: at B=31 the
inclusive u=2^31 needs 32 unsigned bits and cannot be represented by one
field-faithful M31 integer equality. Signed score conversion and u=2^k h+l
need explicit limb/range consumers and static certificates under A3. A change
to attention score alignment/domain additionally requires RFC-0009 review.

Corrected D requires the full indexed correction C(t)=D(t)-P_k(t), despite
C having just four possible values. The research corrected API rejects B>15
before allocation, including validation/evaluation paths. This resource bound
does not restrict the wider two-table P_k API or silently replace D by P_k.
There is no new commitment, challenge, weight pass or waived lookup error term.

## 4. Reproduction and limits

Run `python3 research/cqis-tables/check_wide_exp.py`. The
[artifact](../research/cqis-tables/wide-exp-candidates.json) records six wide
configurations and 305,286 independently checked sub-table entries, including
B=31 at both extreme input scales. Per case, 10,000 seeded full-domain draws
plus endpoints/split boundaries are deduplicated, checked against independent
H/L rounding and enclosed against the full real target. Wide virtual domains
are sampled, not exhaustively enumerated. Additional checks cover minimal and
maximal splits, tail-bound transitions, metadata/certificate/shape mutations,
out-of-domain inputs and early correction-resource rejection. The original
27-case artifact and all activation/GeLU/RMSNorm artifacts remain unchanged.

Recommendation: carry explicit split identities, full index bounds and resource
costs into the complete A2 registry contract. These research checks do not
establish native NC coverage, Rust/NumPy inference parity, static certificate
admission, attention integration, model fidelity or GPU parity.
