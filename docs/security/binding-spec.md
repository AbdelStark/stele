# Binding specification (public good) — what an inference proof must bind (task E12-09 completes this)
Every edge of the claim graph (RFC-0007 §4), every PCS check, every public-input field, with: the tensor pair bound, the
reduction that binds them, the control id that demonstrates the binding, and the RFC section. Provers of other
systems can be run against the same controls (`stele controls --target <prover>`).
