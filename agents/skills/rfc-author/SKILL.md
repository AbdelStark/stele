# RFC author
Read: RFC-0000, `agents/templates/rfc.md`, glossary. Every protocol RFC has the eight mandatory sections; every random
challenge has a ledger line; every binding has a control id; every cost claim is a formula in cost-model symbols.
Amendments are append-only; never change Accepted text in place.
