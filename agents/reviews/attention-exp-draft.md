  exact definitions and full supported domains. No Accepted text, production
  cut, interface or function registration changes.
- Challenges: complete index/range/lookup verification precedes parent A3.
  Expected maximum metadata, representation, all source/view roots and all
  verified states precede parent weights and Instance/Round/Final messages.
  Every multiplicity commitment precedes all lookup challenge pairs.
- Claims: exact byte-derived lookup columns, multiplicities and canonical
  table denominators have complete consumers. Every parent original is
  evaluated at its actual receipt point, including the expected public mask.
- Bindings: tests-first controls target every external/auxiliary root, tuple
  column, compression-preserving final, multiplicity and all parent originals.
  All primary and eight parent-original controls passed. Genuine corrupted/
  partial/padded-table proofs, direct-nearest and E=0 controls, and actual

  remainder proofs additionally rejected at the product/correction equations. The first strict-remainder fixture changed byte width at E=8;

  Runtime assertions check complete totals and every challenge label. The
  primary and first two matrix proofs matched exact accounts; accounting gate

- Bounds: actual ranges give H,L,q,output<=Q<=16384 and r<Q. Product sides

  exclude those tuples from membership. Complete valid canonical rows exclude
  file padding, whose(0,0) would falsely admit exp(0)=0. Internal fraction-tree
  padding remains neutral. E=0 retains every child and arithmetic consumer.

  bounded immutable expected-descriptor caches. No float or challenge retry.

  This revealing Python study claims no GPU parity.
- Cost: O(N) byte views, full canonical table generation and complete
  c_x/c_sc/c_lu/T_misc consumers. No benchmark, fitted constant or weight pass.
- Verifier: expected metadata determines dimensions and namespace; strict keys,
  canonical fields, actual source joins and complete verifiers reject supplied
  receipt/table authority. Native no_std is unchanged; no private PCS claim.
- Glossary/history: existing source/range/claim vocabulary; append-only Draft

  No production control or profile credit is claimed.
