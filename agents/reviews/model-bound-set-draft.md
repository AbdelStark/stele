# Scoped arithmetic collection — same-author skill review

Scope: Draft RFC-0004 A3/A6–A10, preserving the inner schemas and Accepted
RFC-0022 RMSNorm bytes. Codex-root applies cqis-numerics, rfc-author and
soundness-auditor; not independent audit. Evidence:
[scoped collection study](../../research/cqis-checkpoint/BOUND-SET.md).

- Public items: regenerate a fixed twelve-family arithmetic-template collection
  from independently expected canonical config/artifact identities; validate
  every byte against that regeneration. No production or Accepted API changes.
- Challenges/absorbs: none; no transcript, degree or probabilistic loss changes.
- Claims/consumers: no proof claim or complete proof plan. Expected config/physical
  bytes are checked by the existing loader; the collection retains both hashes.
  Actual source/range/branch/index/table consumers and complete registry data
  commitments remain separate. A numerical Model alone is not authority.
- Bindings/controls: BoundSet catches omissions, duplicate/reordered entries,
  family/role collisions, equal-record deduplication, header/length/content
  mutations and reuse across different expected scopes. Identity/ArtifactDigest
  reject altered sources under old expected hashes; Capacity precedes oversized
  frame or source materialization. No catalog control credit is claimed.
- Ledger: no lines change; required accounting gate preserves existing coverage.
- Static bounds: all twelve closed adapters are unchanged. Actual gain/code/
  mantissa changes leave records unchanged; exponents come from validated model
  bytes and select scaled records. No supplied certificate selects metadata.
- Padding/masks: no proof padding or mask is admitted here. The count 25L+B+5
  covers scoped templates only; shared templates are not concrete source claims.
  Existing rotary entries remain present even when rotation is absent.
- Determinism: fixed family and model-role orders, explicit duplicate keys,
  little-endian lengths, no supplied record iteration order, identical records
  retain every role. Hashes distinguish semantically equal numerical states.
- Parity: independent outer struct framing and explicit role/count oracle;
  shared inner codecs and loader are disclosed. Existing primitive native
  evidence is inherited; no new native/GPU collection or inference-proof parity.
- Costs: full bounded model reconstruction plus derivation/copy/comparison of
  every record; no streaming or performance claim. Preparation belongs to
  T_misc/T_witness; no measured constant, cut or inference weight-pass change.
- Verifier: production no_std untouched. Supplied lengths never drive parsing,
  loops or allocation. Existing model-loader caps and 32 MiB frame cap apply;
  this Python checker is not a succinct certificate or source verifier.
- Glossary/history: append-only Draft evidence, original blocked acceptance
  unchanged and all prior pinned baseline/block-variant fields preserved.

I tried to break it by removing one of three identical norm records and
rebuilding the complete outer frame, and the control BoundSet rejected it.
Distinct proof representations and source-role mappings yielding the same
numerical Model also reject when their collections are reused across expected
scopes. This does not authenticate an expected hash's provenance or replace
an actual range, lookup, PCS or source consumer.
