# Configured-output review in progress

Codex-root applies cqis-numerics, gkr-reduction-author, rfc-author and
soundness-auditor. This is a same-author review, not independent audit.
[Scope and evidence](../../research/cqis-bounds/NORM-CONFIGURED-OUTPUT.md).
Control execution, complete matrices, maxima and gates remain pending;
this checklist is not a completed sign-off.

- Public items: revealing Draft RFC-0004 A3 composition for RFC-0022 §2.3.
  Four complete children bind configured factors, signed sources, reciprocal
  product and selected rounding. No Accepted role, cut or profile change.
- Challenges: no parent challenge. The final context binds the complete
  function/role bytes, fifteen expected roots, verified branch, right-branch
  total root and four verified states. Every child retains its full transcript.
  Branch selection follows complete factor verification and actual rooted flags.
- Claims: no new algebraic claim. Shared roots join the actual signed q/xy
  to product and rounding; actual B/h/L byte slices determine scalar roots.
  Every inherited original consumer remains mandatory, including at zeros.
- Bindings: all fifteen root mutations, changed right total, supplied selectors,
  alternate branch payloads and valid substituted xy/q children rejected at
  their named consumers. Zero-product J/B/h/L substitutions and both unused
  left-root controls remain under validation.
- Ledger: sum all four complete accounts and concatenate lookup identities
  in child order. Preserve the factor-only selection reduction, product
  identity and product reduction fields explicitly. Independent child-account
  helpers check these terms and all draws. No reduction is squared. Matrix
  receipts and the accounting gate remain pending.
- Bounds: all schemas derive from expected norm parameters; no observed
  maximum changes a child cap. The complete children retain whole signed
  ranges, integer column bounds, positive factors and strict remainders.
  Exact byte joins add no new field equation or faithfulness assumption.
- Padding: actual child sources retain expected zero padding. Left qd/r
  roots use exactly16N zero slots; right division retains both masked scalar
  broadcasts. All factor slices have fixed lengths16/16/8 from the verified
  64-slot bundle. No whole scalar is substituted for the byte representation.
- Determinism: fixed child/role order and explicit branch byte; expected
  schema determines all dimensions and namespaces. The maximum identity
  corpus checked every child span for overlap. All10000 independent NumPy
  source/output cases passed, including shifts-16 and90; the digest is frozen.
- Parity: native CPU/SIMD/CUDA unchanged. NumPy uses int64 for bounded products
  and Python integers through object arrays for wide division; no float path.
  Complete proofs in both fields/repetitions remain under validation.
- Costs: O(N) exact source joins plus all four complete range/hash/algebraic
  consumers in c_a/c_sc/c_lu/T_misc. No new parent A3, benchmark, measured
  constant, per-row proof loop or additional weight pass.
- Verifier: native no_std unchanged. Metadata precedes payloads. Strict
  expected roots and branch-dependent proof keys reject ignored alternate
  payloads. Supplied receipts and producer states are never accepted. Whole
  rounding arithmetic is confined to the producer; verify uses child consumers.
- Glossary/history: append-only Draft/accounting evidence. Full normalization
  must still bind the same X statistic, numerator, normalized interval and
  configured rsqrt. Native/model/private inference, fidelity and original
  task criteria remain open. Remaining controls, matrices, maxima and gates
  are still required before this review can be completed.
