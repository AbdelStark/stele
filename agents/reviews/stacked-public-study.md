# Q20 closed public-stage review

Reviewer: codex-root, also the author; rfc-author, gkr-reduction-author and
soundness-auditor. Not an independent audit. Decision: publish research evidence;
retain RFC-0006 A4 and its companions as Draft, E3-06 blocked.

- Public items/RFC: candidate Stack/A1 wrapper under formal/stacked-statement.md
  §3/§5. Research only; no core behavior, registry or dependency change.
- Challenges/absorbs: actual original public bytes in Public, then complete Stack,
  derived A1 Instance, every round before its draw and all finals before continuation.
  Reuses the existing Transcript object/challenge; no extra random draw or RLC.
- Claims/consumers: coefficient independently evaluated in canonical coordinates;
  every original public input, including unused inputs, consumed at that same point.
  No raw framed receipt escapes. The relation is supplied by a trusted caller;
  it does not derive an inference operation from a tensor id/output claim.
- Bindings/controls: one-value wrong-layer/draw-order unused finals reach and fail
  the actual research public consumer. Empty-P scalar source-final and omitted-prior-
  Final examples reject for their named reasons. No production NC catalog credit.
- Ledger: check m*delta for degree 0..4 in both fields; no changed production line,
  Q12 resolution, composition proof or profile certification.
- Certificates: field relation only; no integer-identity or CQIS certificate claim.
- Padding/masks: coefficient built from one valid Boolean table, independently of
  its verifier evaluator; original public padding must be zero before replay.
- Determinism: canonical Public/Stack bytes and both explicit frame orders. Same
  statement/input seed produces the same messages and continuation in this oracle.
- Parity: 1,200 seeded stages plus scalar/no-original boundaries; shared A1/field
  primitives mean this is not independent Rust differential or GPU proof parity.
- Cost model: dense preparation, multiple table copies, bound public bytes and
  direct original consumer work are charged explicitly; no measured constant,
  additional production weight pass or distributed execution claim.
- Verifier: production unchanged. Candidate shape/field failures precede mutation;
  later failures invalidate the attempt. Production admission/errors/no_std pending.
- Glossary/source: full public values are fixed inputs, not digests or flags asserting
  that a private index opening/CQIS table has been authenticated. Those paths remain.

I tried to break original consumption with one wrong-layer unused final: the
conditional reduction accepts it, but the actual public consumer rejects it with
ClaimMismatch. That distinction is preserved, not relabelled complete inference.
