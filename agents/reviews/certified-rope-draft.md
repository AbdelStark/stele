# Certified rotary coefficients: Draft review

Same authoring agent (codex-root), cqis-numerics, rfc-author and soundness-auditor
passes; not independent review or protocol acceptance.

- Public items: research Parameters, codecs, generation/enclosures and validation
  investigate RFC-0004 §5.4 / Draft A7. No core crate imports this code.
- Challenges/absorbs: none; no transcript or random error-budget change.
- Claims/consumers: none admitted. Public table/position/config associations,
  rotation/requant/range relations still need actual proof consumers.
- Bindings/controls: descriptor-byte mutations, noncanonical rational aliases,
  wrong expected config, altered table/certificate and unsupported parameters
  reject in research. None supplies NC-0106 or a native source binding.
- Ledger: unchanged; existing accounting gate remains mandatory.
- Bounds: root inequalities, rational pi/Taylor bounds, outward doubling and
  rounding-interval agreement establish returned coefficients. Bounded refinement
  rejects uncertainty. These are public generation checks, not field certificates.
- Masks/padding: only real table rows are generated; public MLE padding/selection
  remains unresolved and no padded-query claim is made.
- Determinism: fixed precision order, canonical parameters/bytes, absolute positions;
  typed memo keys preserve rejection of bool aliases after an integer cache hit. No frequency/angle quantisation before trig.
- Parity: 10,000 independent Arb comparisons, full finite table, difficult refinement
  and projected-attention integration; no native CPU/SIMD/CUDA or model parity claim.
- Costs: O(L*r) preparation/data, bounded memo and materialization cap; verifier
  public-MLE cost is open. No measured constant, cut or weight-pass change.
- Verifier: unchanged no_std code. Descriptor equality is not proof authentication.
- Glossary/spec: append-only RFC/agenda additions; original task criteria preserved.

I tried to break it by changing each descriptor byte, substituting a table value
and altering a rounding certificate, and the control rejected it with Descriptor
or Identity, Table and Certificate respectively. Frequency pre-rounding also
produces a concrete mismatch. Native registry, remaining variants, full forward,
proof consumers and fidelity are still required; A7 remains Draft.
