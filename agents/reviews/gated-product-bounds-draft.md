# Gated-product bounds — same-author skill review

Scope: Draft RFC-0004 A3/A8. Codex-root applies cqis-numerics, rfc-author and
soundness-auditor; not independent audit. Evidence:
[gated-product study](../../research/cqis-bounds/GATED-PRODUCT.md).

- Public items: conditional source-to-product records and per-layer templates
  for the A8 exact product. Accepted RFC-0022 and native APIs are unchanged.
- Challenges/absorbs: none; no FS order, degree, random challenge or loss change.
- Claims/consumers: no proof claims. Checked products feed gated row conversion
  and scaled down projection. Up/SiLU source ownership, function membership,
  range/source consumers and complete certificate-set association remain open.
- Bindings/controls: IntegerRelation catches p-separated output and offset-product
  aliases after rebuilding all local columns; SourceDigits catches either
  changed factor. Witness/Range/Boundary/Relation/Certificate/Encoding catch
  named shape/type/range/carry/static/byte changes. No production NC credit.
- Ledger: no lines change; accounting gate must preserve existing coverage.
- Static bounds: only d/fu/E select the schema. All factor-format bounds are
  fixed; actual magnitudes never tighten a record. Uniform rhs caps are larger
  than actual ranges but every column side is still <=294399<p/2.
- Padding/masks: exact d-element source rows; missing/extra rows reject. No
  source selector or query-padding policy is inferred. Those remain consumers.
- Determinism: exact product, fixed offsets/coefficients and byte framing; zero
  products use the same relation. No sign choice, requantisation or saturation.
- Parity: exact/NumPy products, column oracle and model/checkpoint composition.
  Shared certified SiLU and generic primitives are disclosed; no native/GPU
  product parity or fidelity/inference admission claim.
- Costs: O(d) actual-row work/data and fixed per-layer records; no benchmark,
  measured c_a/T_witness constant, new cut or additional weight pass.
- Verifier: production no_std untouched. Research whole integer/source/digit
  checks are not succinct authenticated consumers or complete set validation.
- Glossary/history: append-only Draft evidence and unchanged original criteria;
  baseline and separate block-variant fixture fields remain intact.
