# Q20 public-MLE algebra review

Reviewer: codex-root, also the author; rfc-author, gkr-reduction-author and
soundness-auditor. Not an independent audit. Decision: retain RFC-0006 A4 as
Draft and E3-06 as blocked; publish candidate algebra and reproducible checks.

- Public items/RFC: research functions and a Draft formal note address A4's kinds,
  padding and evaluation-cost questions. Nothing is imported by a core crate.
- Challenges/absorbs: none implemented or assigned. Complete descriptor bytes,
  registry and transcript order remain acceptance prerequisites.
- Claims/consumers: no claim is emitted or discharged. A public table/list requires
  actual bound source values; a committed list requires its real prior consumer.
  The study's supplied vectors are not authenticated inputs to an inference proof.
- Bindings/controls: no new production binding or catalog credit. Actual NC-0203,
  source identity, coordinate and continuation controls remain delivery requirements.
- Ledger: unchanged. These are deterministic table-evaluation identities; they add
  no challenge or loss and establish no Fiat-Shamir/profile bound. Q12 stays open.
- Certificates: no CQIS integer reduction. Borrow/carry bits describe the public
  Boolean mask; they are not private arithmetic witnesses or bound certificates.
- Padding/masks: tables are zero outside real domains before extension. A concrete
  equality counterexample rejects separate unpadded/validity-MLE multiplication.
  Masks include the current position, and the window's upper distance is strict.
- Determinism: fixed seed, canonical MSB coordinates, fixed low-bit state traversal;
  only exact M31 arithmetic. Zero-field states can be skipped in this research code;
  no constant-time or production side-channel claim follows.
- Parity: each kind matches 10,000 direct M31-table queries; rectangular equality
  products, malformed shapes and 63-bit mask identities have additional checks.
  This is not QM31/OM31 production or GPU parity. Random table values do not test
  actual CQIS RoPE generation, identity or rotation semantics.
- Cost model: T_misc formulas explicitly charge equality vectors/table storage.
  The carry/borrow mask state has fixed size and O(bits) work; no measured constant,
  fitted value, benchmark, weight pass or performance claim changes.
- Verifier: unchanged scaffold/no_std boundary. The proposed source-authentication
  and full statement/ownership contract must be completed before implementation.
- Glossary: no new cut, commitment, profile or inferred source authorization.

I tried to break the candidate padding rule by multiplying separately extended
selectors; it disagrees with direct padded equality (252 versus 2147481337).
This is algebraic evidence, not rejection by a production verifier or NC credit.
