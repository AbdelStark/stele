# Same-author review: exponential index decomposition

This is Draft RFC-0004 A3/A6 research for RFC-0021 §2.1 and RFC-0009 A1,
not an independent audit. [Scope](../../research/cqis-bounds/ATTENTION-EXP-INDEX.md).

- RFC scope: product and nearest/corrected indices retain the complete B/k
  domain and inclusive endpoint. Direct nearest has no split. No Accepted
  definition, table, model cut or production interface changes.
- Challenges: four complete range/lookup verifiers run first. Exact maximum
  instance metadata, representation, four roots and four verified states
  precede parent ZeroWeight and the inherited A3 Instance/Round/Final schedule.
- Claims: all five original views use the actual receipt point. Shifted h
  bytes come only from the verified source; absent high bytes are public zero.
  Full source/vector consumers remain mandatory for masked/padded positions.
- Bindings: primary controls passed three external/one carry root mutations,
  all arithmetic substitutions and u=M31+1 versus1. All original/boundary and
  complete maximum-composition suites also passed after the diagnostic repair. A split replay rejected at
  High:CapRelation:ClaimMismatch; the first test expected the wrong diagnostic.
  Only that expectation changed, with the first failed run retained.
- Ledger: four independent lookup identities and unsquared reductions remain.
  Parent2a+4, total38a+22+7*(bu+bh+bl) and nonlookup draw counts matched the
  first proof. The append-only accounting line retains every inherited term.
  The repository accounting gate remains pending.
- Bounds: expected caps give u<=min(2S,2^B), h<=2^(B-k), l<2^k. Four byte
  equations have sides<=33023<p/2. Carries are bounded by2^(k mod8), with
  initial and final zero. Thus reconstruction is an integer identity and
  the last high index forces low zero. Bounds never depend on observed data.
- Padding/masks: the maximum instance derives the expected causal/window/
  block mask. Every range caps masked/padded entries at zero. Shifted views
  keep all four byte columns, including required high zeros.
- Determinism: fixed range/view/byte order and canonical integer metadata.
  There is no floating point, timing-dependent reduction or challenge retry.
- Parity: native CPU/SIMD/CUDA unchanged. The10000-case independent NumPy
  divmod/prefix-sum corpus passed all235 B/k pairs, both represented function
  families, all byte widths and namespace endpoints. Both proof fields and
  repetition counts passed the complete16-case matrix with exact accounting;
  actual maximum source composition passed at delta=2^31.
- Cost: O(N) byte views, four complete ranges/lookups and one A3 charge
  c_x/c_sc/c_lu/T_misc. No benchmark, fitted constant or weight-pass change.
- Verifier: expected metadata controls sizes, identities and split. Strict
  proof keys/fields and full child verification reject supplied authority.
  This Python reference makes no native no_std or private-source admission.
- Glossary/history: existing attained/source/range/claim vocabulary. Draft
  evidence is append-only. Original E5/E7 criteria remain blocked and intact;
  no catalog control or profile credit is claimed.
