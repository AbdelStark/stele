## 2. Gap closed in this PR

The table-id-in-cqis_id claim was only implied. Existing tests showed that
H(Registry) enters cqis_id, but none tied a configured component to the
Registry bytes. `rejects_registry_with_changed_component_data_digest` covers
every role of all six fixture Models (both families). For each role it checks
that the RepresentationId is in the Registry. For each component it finds the
canonical descriptor followed by H(regenerated data) in the Registry bytes. It
then flips one byte of that digest and requires `Registry::decode` to reject
with `TableData`. Mutation check: with the digest comparison in
`registry.rs:167-169` disabled, the test fails. It passes once restored.

LayerNorm mode 4 edge cases were already covered (section 1), so no test was
added for them. No API was added.

## 4. Same-author adversarial review

The same author is acting in the review roles. This is not the sign-off.

- **Control loss.** Every control appears in at least one owner's acceptance,
  quoted verbatim (checked by script: NC-0404 E6-00/E12-05a, NC-0405
  E7-06/E7-08, NC-0412/0413 E6-00, NC-0414 E6-00/E12-05a). E3-08 still lists
  all of them.
- **Cycles.** A topological check over all 140 tasks finds no cycle. E3-08
  reaches E3-08a and no path from E3-08 returns to E3-08. Each owner (E6-00,
  E12-05a, E7-06, E7-08) reaches E3-08a and not E3-08. Nothing depends on E3-08.
- **Credit inflation.** E3-08a claims only the section 1 items. The lookup
  verifier still accepts a caller-chosen `Table`. The link from a lookup to its
  configured role is not built here; it is an E6/E7 obligation.
- **Unblocked work.** E15-07 depends only on E3-08a and is now actionable.
  E6-00 stays blocked on its own contracts and E4-05. E12-05a still waits on
  E4-05, E6-02 and E8-05a. E7-05/06/08 stay blocked on their own amendments.
- **Residual risk.** The NC-0405 owners E7-06 and E7-08 are blocked. Until they
  unblock, the recombination control has no runnable home. This was already
  true before A3.
- **Soundness ledger and cost model.** No challenge, loss line, transcript,
  constant or weight pass changes.
