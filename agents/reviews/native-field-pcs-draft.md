# Conditional field PCS contract review

Codex-root applied pcs-engineer, rfc-author and soundness-auditor. A separate
read-only agent reviewed the complete draft and finite parameter calculations.
This is internal agent review, with no independent audit claim.

- Public items: Draft RFC-0010 A9, RFC-0012 A10 and RFC-0020 A5 specify a
  conditional field-source contract. Original A1/A3/A6/A7 tasks stay open.
- Challenges: certificate row weights follow expected context; all column
  draws follow the full row message. Rejected attempts advance the whole
  transcript; unused limbs are discarded. Response blocks bind before any
  continuation. A completed certificate ID never enters its own transcript.
- Claims: the named reductions adapter invokes actual A1 verification and
  consumes all returned original points/values against the exact prebound
  source roster. Its verifier receives no source tables or callback.
- Bindings: proposed native controls cover context, certificate identity,
  canonical columns, query order and unused A1 originals. They have not run
  because native implementation is not authorized by these Draft amendments.
  The pure policy study provides no production NC coverage.
- Ledger: certificate tensor/query, per-opening query, A8 hash lifetime and
  A1 SC terms remain separate. Sampler exhaustion is availability loss. Every
  hash attempt still belongs in Q12's resource budget; no profile is admitted.
- Bounds: all 59 query pairs satisfy exact integer inequalities and fail at
  q-1. All 30 M31 index thresholds are checked. No integer inference identity
  or dynamic bound certificate is introduced.
- Padding: version 1 requires logical dimensions to equal the field matrix
  dimensions. Circle's codeword length is a power of two. Packed/CQIS padding
  requires its own source relation and cannot be inferred from this layout.
- Determinism: native MSB order, fixed byte lengths, exact code identities,
  explicit label suffixes, fixed query counts and repeated-draw responses.
- Parity: the current evidence is exact policy arithmetic, not native/Python
  proof parity. Actual two-field byte parity remains a delivery gate.
- Costs: complete registration, row formation, encoding, scalar checking,
  authentication and retained buffers are charged. No measured constant or
  weight-pass improvement is claimed.
- Verifier: checked size arithmetic and fallible allocation are required.
  The all-error abort rule forbids retries, rollback and usable partial receipts.
  Owner review also requires complete A1 preflight, single-path verification
  of repeated draws, explicit shape/domain/exhaustion errors and observable
  local usage on failure. Conditional records retain certificate obligations;
  external composition owns deterministic lifetime/adversary caps.
- Glossary/history: append-only Draft amendments; exact dependency changes
  are proposed without modifying Cargo. GKR gains no authentication callback.
