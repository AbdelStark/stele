# Explicit model execution dependencies — same-author review

Codex-root applies cqis-numerics, rfc-author and soundness-auditor to Draft
RFC-0004 A3/A10 and RFC-0005 A1 references. This is not independent audit.
Evidence: [execution graph study](../../research/cqis-checkpoint/MODEL-FLOW.md).

- Public items: expected-config graph derivation, byte comparison and public
  numerical execution through explicit physical/operation dependencies. Existing
  artifact/config/function contracts are unchanged; no native plan admission.
- Challenges/absorbs: none. No transcript path, degree or random challenge added.
- Claims/consumers: no emitted proof claims. Physical nodes resolve from separately
  expected artifact bytes through the existing loader; numerical operands use
  declared edges. Self-selected hashes establish no external provenance. Private
  source/PCS, virtual tensor, range, lookup and branch consumers remain open.
- Bindings/controls: Flow rejects rebuilt same-shape source/edge/function/template
  substitutions, order/count changes and 255 byte mutations. Identity and
  ArtifactDigest reject wrong expected scopes. No production NC credit.
- Ledger: no new line; required accounting gate checks unchanged existing ledger.
- Static bounds: references retain every existing family/role once; they do not
  enforce the arithmetic records. Shapes/graph caps derive from configuration;
  no observed learned or activation values tighten a bound certificate.
- Padding/masks: actual sequence prefix is numerical input. Projected attention
  internally uses canonical causal positions. This is not padded Tensor IR or
  valid-row/selector authentication; rotation/row bundles are explicitly composite.
- Determinism: fixed source/operation order, sorted JSON keys, exact integer/hex
  fields and canonical inputs. Set/dictionary membership never selects node order.
- Parity: exact full-model reference replay; no native full-model or GPU proof
  parity claim. Thirty mixed-unit cases and the pinned six-token continuation
  pass. Shared primitives, JSON and role-set helpers are disclosed.
- Costs: bounded metadata plus full numerical replay in T_misc/T_witness, with
  intermediate last-use release and scoped temporary attention caches. No measured
  constant, ledger benchmark, streaming guarantee or inference weight-pass claim.
- Verifier: production no_std unchanged. Supplied graph bytes are bounded and
  compared against regeneration; they select no allocation or evaluator. Existing
  loader/model/block capacity checks apply before execution. No check bypass added.
- Glossary/history: Accepted text unchanged; Draft evidence append-only; task
  criteria remain blocked. Full plan, native/fidelity and private proof delivery
  remain required. Node containers do not silently become committed tensors.

the expected model identity and rebuilding valid graph framing, and the control
Flow rejected it before execution. Equal gain values also did not permit swapping
their source roles. This is a numerical binding check, not PCS authentication.
