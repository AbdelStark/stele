# Restored-value review in progress

Draft RFC-0004 A3/A6 and RFC-0009 A2. Codex-root applies cqis-numerics,
gkr-reduction-author, rfc-author and soundness-auditor. This is a same-author
review; it is not independent audit. [Scope](../../research/cqis-bounds/ATTENTION-VALUES.md).

- Public items: consume actual two's-complement code sources, per-position
  scales and bounded offsets U=S+s*V. No Accepted role, cut or profile changes.
- Challenges: full expected schema/positions/ids, three external roots,
  every auxiliary root and all complete verified child states precede parent
  weights, rounds and finals. Static scales are exact expected public bytes;
  dynamic scales retain a complete range. No supplied receipt is accepted.
- Claims: five restoration views, four dynamic predicate views and two
  zero-scale views have independent consumers at their exact emitted points.
  Zero-hidden scale/raw/sign finals and a false public real-row mask rejected
  at ClaimMismatch. The signed source retains every inherited original.
- Bindings: source/scale/output root changes and fresh false offsets rejected.
  Separately valid code and scale substitutions rejected their pinned roots.
  Both false predicate directions and a changed predecessor rejected; valid
  source/range children with nonzero code at zero scale failed ZeroScaleCodes.
- Ledger: static A3 numerator64a+9+7bo and draws27a+4+3bo per label; dynamic
  numerator67a+30ar+26+7bo and draws28a+13ar+11+3bo. Five/eight separate lookup
  identities retain unsquared reductions. All20 dynamic/static receipts and
  exact draw counts matched across both fields/repetitions. The repository
  accounting gate remains required.
- Bounds: complete signed8 reconstruction, tighter whole magnitude cap,
  whole scale and offset ranges precede every field lift. Restoration sides
  are at most16908030<p/2. Static Cmax derives from configured scale. The
  independent corpus checked all output widths and maximum metadata; no
  observed bound authorizes verification. The M31 offset-alias and tighter
  static-cap controls passed at their actual range consumers.
- Padding: raw codes and every range retain zero padding. Only expected real
  entries receive offset S; position scales broadcast to their exact channels.
  Padding and nonboolean predicate controls passed at actual cap consumers.
  Masked real value sources remain present. All four external output planes
  are bound, including exact zero extension from compact ranges.
- Determinism: fixed role/child order, reserved inactive ids and canonical
  expected positions. No float, retry, table cache or iteration over supplied
  dictionary order. The10000-case NumPy integer corpus passed and is frozen.
- Parity: native CPU/SIMD/CUDA unchanged. Independent two's-complement and
  planar byte encodings agreed with every corpus root. Actual dynamic/static
  prepared-row composition passed, including valid alternate source rejection.
  Complete projection-row, GQA/cache
  and physical/model ownership remain separate requirements.
- Cost: O(N+R) views and A3 producers plus complete inherited range/hash/MLE
  consumers in c_a/c_x/c_sc/c_lu/T_misc. No benchmark, fitted constant or
  weight pass is claimed. Each wide child stays within the existing capacity.
- Verifier: expected metadata and capacity precede payload access. Exact
  proof keys, auxiliary roles, lengths and canonical parent fields are checked.
  No verifier-side plaintext restoration grants acceptance. Native no_std
  is unchanged; revealing byte roots confer no private PCS admission.
- Glossary/history: append-only Draft plans/accounting. The original task
  statuses and criteria remain. All20 matrix proofs passed; two full-row proofs, gates, weighted
  sums, normalization, native/private inference and fidelity remain open.
