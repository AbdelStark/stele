  and static bounds. Draft RFC-0004 A3 governs these revealing consumers.
  The full norm parameter domain is retained; the receipt proves this role
  only and does not admit native/private/model ownership or full normalization.

- Bindings: each operand role has one-value and independently valid alternative

  Actual statistic-to-numerator root composition rejects a substituted statistic.

  product whole bounds do not imply that tighter statistic bound. Static
  column sides, actual carries and both zero endpoints give integer equality;
  the closed N bound follows afterward, never from independent digit caps.
- Padding: full external S has8 slots even with a four-byte range child.
  Derived public operands use exact zero extension, and all padded product
  output digits and carry boundaries remain ranged. No prefix-only root check.
- Determinism: fixed role/plane order, exact integers, canonical norm function
  bytes and closed bounds before payloads. NumPy object-integer values and
  int64 byte convolutions agree, including maximum supported parameter values.
- Parity: native CPU/SIMD/CUDA unchanged. These differential and complete
  field/repetition checks are research evidence, not independent protocol audit.
- Costs: O(B) source views plus complete c_a/c_sc/c_lu/T_misc inherited work.
  No per-element proof loop, measured constant, benchmark or extra weight pass.
- Verifier: native no_std unchanged. Strict expected schema, lengths, roots
  and field limbs. Verification constructs byte views without recomputing N
  as a whole integer; arithmetic assemblers confer no acceptance.
- Glossary/history: append-only Draft/accounting evidence and blocked original
