# E0-06 consolidation review

The integration preserves all published heads from PRs 191–242 by ordinary
merges. It also includes committed local attention capacity, composition,
maximum, offset, value, output-conversion and spool work, plus the original
measured reference-field history. Opening implementations remain uncommitted
in their original worktrees and are excluded from this integration.

The obsolete encoder branch at `1cd763a27a475f88581a5c29a75db3f732251bd1`
is preserved by an explicit history-only merge. Current RFC-0010 A4 uses the
sealed encoder and bounded regeneration; the old branch retained full graphs
and exposed setup/distance metadata. Restoring that API would undo accepted
current behavior. Its public-coefficient implementation/tests already match
current code. Old ADR-030/031 numbers collide with later decisions, so their
original text remains in history rather than becoming new current authority.

The original [encoder ledger](../../bench/ledger/e4-01-native-expander.json)
is retained byte for byte from that branch. It identifies measured source
`88340649f35d35da3ed2fb97d1929ce29940a999`; it does not measure the current
encoder or certify a distance, profile, GPU or inference result. Current
E4-08 measurements and cost-model text remain authoritative for current code.

The normal research inventory retains every command from the published source
heads. The full inventory preserves all 63 inherited full-size commands and
adds documented local full modes. Experimental/Draft task completion remains
open wherever full-size, native, private-source or model evidence is missing.

The owner requested this single consolidation despite its size. Subsequent
implementation tasks must validate and merge sequentially. CI scheduling
changes add no soundness claim and reduce no native parity corpus.


E4-03a is queued as ready while E0-06 is active. Its delivered certificate
pieces remain integrated; its original opening/adapter criteria are unchanged.
The preserved opening work resumes only after this integration merges.
