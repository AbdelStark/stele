Workflow 03 checklist:
- Public items: research index/parser, exact file/tensor membership, manifest,
  typed source and preparation identities. No core or admitted passport API.
- Challenges: none. Source hashes are deterministic research identities, not
  transcript challenges. Actual hash-query accounting remains a consumer duty.
- Claims/consumers: none; expected source digests and Specs require independent
  authenticated authority. Self-chosen file hashes cannot establish a model.
- Bindings/controls: local hash/location/set/metadata checks only; no catalog
  credit. Actual passport/source/plan/PCS/wrapper/certificate controls remain.
- Ledger: no label/loss/profile change; accounting gate retained.
- Bounds: u64 payload/file totals, bounded UTF-8 filenames/index bytes, u32 counts;
  no observed quantity becomes a static field certificate. Native resources open.
- Padding/masks: inner source/record padding rules retained; manifest has exact
  framing and tags. No new mask, cut or committed tensor.
- Determinism: snapshot immutable shard bytes and expected Specs, sorted filename
  framing, exact raw index/file hashes, no name normalization or implicit aliases.
- Parity: 10,000 bundles match unsharded retained-array artifacts and independent
  manifest bytes. All 64 checkpoint tensors survive 2/3/7/64 local repartitions.
  No published sharded-checkpoint, forward, fidelity, GPU or performance claim.
- Cost: source/metadata/hash preparation is T_misc, with whole-file/array research
  storage. No fitted constant, extra inference weight pass or commitment count.
- Verifier: no_std production code unchanged. Typed identity is emitted only;
  full outer parsing/configuration authority and actual consumers remain open.
- Glossary: a bundle digest is not a file's digest_hf. Correct source reproduction
  is separate from commitment binding, certificate validity and private proof.
