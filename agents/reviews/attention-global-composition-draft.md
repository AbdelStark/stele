# Global attention composition review in progress

Same-author review, not independent audit. The scope and account preceded
implementation; tests first rejected the missing module. Complete controls,
matrices and full-size proofs must pass before approval.

1. Public items: Draft RFC-0004 A3/A6/A8 and RFC-0009 A2. The scope fixes
   the complete block roster, O/Z joins, flat stream and output conversion.
   Accepted semantics and production cuts remain unchanged.
2. Challenges: the wrapper draws none. Each complete child retains its
   transcript order. Full expected schema/roles, ordered roots and all 2h+1
   verified child states bind the final wrapper context.
3. Claims: every global offset/probability original is consumed by its
   complete verifier. The same expected O/Z roots feed complete normalization
   inside output conversion, which consumes actual assembled head bytes.
   No supplied receipt or producer sum replaces any of these consumers.
4. Bindings: tests cover both block-root families, both shared O/Z roots,
   head/block order, missing/extra records, Boolean indices and ignored tails.
   Genuine changed aggregates preserve totals; a genuine changed output
   proof preserves final codes. Zero-offset and zero-probability substitutions
   test the positive normalization join. Both primary suites and all four
   field/mode edge cases passed; the original matrix remains in progress.
5. Ledger: sum independent lookup identities and unsquared reductions;
   preserve range/A3 losses, each offset projection identity, offset A1 sums,
   every probability/normalization product identity and the row selection
   term. Runtime child/aggregate equality and the accounting gate are required.
6. Bounds: all arithmetic bounds come from expected metadata and child specs.
   The exact probability adapter picks its minimum legal shift from 1024QS;
   its caps remain the original L/Q caps. All 120 field/quantizer/exponent
   adapter checks passed. Exact normalization arithmetic is unchanged.
7. Padding/masks: every block occurs exactly once. The global offset child
   enforces padded bytes and canonical stream EOF. Its bounded B+1-record
   view cannot hide an extra record from the next outer header/tail check.
   Actual key/mask ownership remains an upstream obligation.
8. Determinism: fixed head/block order, derived identities and exact byte
   framing. Expected roots are copied before consuming the caller's iterator.
   Producer integer sums are used only to construct witnesses.
9. Parity: native CPU/SIMD/CUDA code is unchanged. Both full head/channel
   layouts and both fields passed namespace checks. This research does not
   establish native or GPU parity, or private inference.
10. Costs: upstream proof records stream per head, with retained roots/states
    and one complete output proof. Child/caller/codec peaks remain additional.
    The producer hashes observed block bytes for its context; this is linear
    source work. No benchmark, fitted constant or extra weight pass is claimed.
11. Verifier: native no_std code is unchanged. Expected metadata fixes every
    record window and proof role. Strict child and outer EOF reject ignored
    payloads; every child verifier runs independently on expected roots.
12. Vocabulary/history: existing block, offset, probability, source and claim
    terms are retained. RFC/account prefixes and original task status/criteria
    were checked unchanged. Full per-block/model ownership, O-projection,
    native/private proofs, fidelity and independent audit remain open.

I tried to break it by replacing complete children with genuine proofs that
preserve totals or final codes, and the control for each changed shared
source rejected it. Genuine zero-probability aggregates also rejected at
the positive normalization join in both fields/modes. The original matrix,
full-size proofs, repository gates and complete resource evidence remain
required; this is not approval or independent audit.
