# Masked maximum bounds — same-author skill review

Scope: RFC-0009 A1 requirements with Draft RFC-0004 A3/A6 and RFC-0009 A2.
Codex-root applies cqis-numerics, rfc-author and soundness-auditor; not independent
audit. Evidence: [maximum study](../../research/cqis-bounds/ATTENTION-MAX.md).

- Public items: conditional maximum/difference records and per-layer templates.
  First allowed tie matches the Draft reference, not a new Accepted requirement.
- Challenges/absorbs: none; no FS order, degree, random challenge or loss change.
- Claims/consumers: no proof claims. Checked scores/maxima/deltas compose with
  probability evaluation, raw sums, block aggregation and normalization. Actual
  source/mask/position/range/index/function/PCS consumers remain required.
- Bindings/controls: IntegerRelation rejects coherent attainment, difference and
  strict-prefix aliases. SourceDigits catches changed scores/masks; Position,
  Positions, Selected and Selection catch metadata/source failures. Masked,
  Range, Boundary, Relation, Certificate and Encoding catch named mutations.
  Domain rejects out-of-domain honest differences. No inference NC credit.
- Ledger: no lines change; accounting gate must preserve existing coverage.
- Static bounds: model recomputes S from the expected score policy and takes B/F
  from the function. No observed maximum or supplied record defines a cap.
  Byte sums have sides <=511<p/2, even for the full signed score interval.
- Padding/masks: real queries only, exact actual key rows and absolute IDs, no
  unused tail allocation. Every score is range checked; masked delta/gap are
  zero, all-masked queries reject. Complete membership and query padding need
  their actual consumers; no claim that host masks authenticate causality.
- Determinism: sorted IDs and strict allowed prefix choose the first tie;
  fixed role order and little-endian exact framing, including S=0.
- Parity: independent integer/NumPy and digit-convolution corpus plus model and
  checkpoint composition. Shared primitives disclosed; native/GPU parity and
  fidelity remain mandatory, with no inference admission.
- Costs: O(actual keys) work/data and fixed per-layer records; no benchmark or
  measured constant, cut or weight-pass change. Eventual term: T_attn/c_x.
- Verifier: production no_std unchanged. Research expected-source/whole-range
  checks are not succinct authenticated consumers or complete set validation.
- Glossary/history: append-only Draft evidence and unchanged task criteria;
  all baseline and separate block-variant checkpoint fields remain intact.
