# Attention normalization bounds — same-author skill review

Scope: Draft RFC-0004 A3/A6 and RFC-0009 A2. Codex-root applies cqis-numerics,
rfc-author and soundness-auditor; not independent audit. Evidence:
[normalization study](../../research/cqis-bounds/ATTENTION-NORMALIZATION.md).

- Public items: candidate static division records, plaintext column checker and
  model templates; Accepted behavior and RFC-0022 v1 remain unchanged.
- Challenges/absorbs: none; no FS ordering, random challenge or degree loss change.
- Claims/consumers: no proof claims emitted. Actual sum/divisor/range/function,
  mask/source/head/GQA ownership, block rounding and output conversion consumers
  remain required. A positive expected z does not prove an attained maximum.
- Bindings/controls: canonical digit comparisons reject coherent source-sign,
  divisor, quotient and strict-remainder aliases by multiples of p. SourceDigits,
  IntegerRelation, OutputRelation, Range and Boundary catch their named mutations.
  Research controls give no NC-0100/0101/0109/0500..0506 credit.
- Ledger: no lines change; accounting gate must retain existing coverage.
- Static bounds: only L/W/units/E/policy/mode/drop select caps. Absolute context
  span bounds occupied blocks. Every byte-column side has a strict p/2 bound;
  no observed numerator/divisor or short live row reduces the certified cap.
- Padding/masks: exactly W real totals; masks and padding belong to source
  consumers. Zero total and negative values rounding to zero remain valid;
  negative source zero, zero divisor and undersized block drops reject.
- Determinism: integer arithmetic, exact nearest ties away, fixed role order,
  canonical bytes and zero extension; no timing-dependent iteration.
- Parity: exact Fraction/NumPy corpus, mixed model and pinned checkpoint replay;
  shared inner numerical primitives disclosed. Native/GPU parity remains open.
- Costs: fixed record derivation and O(W) witness/checking; no measured constant,
  benchmark claim, new cut or changed proof weight-pass count.
- Verifier: production no_std unchanged; research whole ranges and digit checks
  are not succinct authenticated consumers or complete certificate-set validation.
- Glossary/history: Accepted prefixes, original task criteria and existing
  schemas preserved. Block rounding/summation remains an explicit prerequisite.
