The root ran the bounded independent reference composition once on the frozen
source. Both reviewers inspected the helper, actual results and all 25 source
hashes. It verifies genuine certificates, calls unchanged A4/A1/A7 and both A9
verifiers, and derives the expected output independently from logical matrix
multiplication. Results: 22 complete honest proofs, 16 targeted rejections
(eight ColumnMismatch and eight ValueMismatch), and eight malformed rejections.
Four attacks swap actual layer/inner coordinates in multi-layer non-Boolean
fixtures; all rounds and retained rows stay fixed. W attacks first pass X's
rebuilt opening. Every honest case repeats complete bytes and verifies a genuine
following A1 instance. This supplies no native NC, Usage, one-pass or memory credit.

I tried to break it by substituting one restored original final under a zero
opposite factor, and the control NC-0307 rejected it with ValueMismatch in the
author-executed reference run. This is an evidence-qualified review statement,
not a reviewer rerun or native catalogue completion.
