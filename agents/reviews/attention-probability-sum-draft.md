# Same-author review: exact probability sums

Draft RFC-0004 A3/A6 research for RFC-0009 §2 step3 and A1. This is not an
independent audit. [Scope](../../research/cqis-bounds/ATTENTION-PROBABILITY-SUM.md).

- RFC scope: Z is the exact sum of actual masked P_hat bytes. Zero standalone
  block contributions remain valid; whole-row positivity uses the actual
  attained maximum and exponential proofs. No Accepted rule or cut changes.
- Challenges: both complete range/lookup states, expected row/E metadata,
  source/output roots and compact scalar root precede the parent A1. Every
  Instance/Round/Final frame is retained. No parent ZeroWeight is introduced.
- Claims: the one original whole-byte source view has an independent full
  hypercube evaluation at the exact A1 receipt point. Actual byte sources and
  multiplicities retain their complete inherited consumers.
- Bindings: root and genuine wrong-sum controls passed. Equal-sum source and
  false-view permutations, M31 scalar aliases, high-plane extension, mask and
  exponent replays, padded entries and dimension-zero false sums reject.
  Actual maximum/exp/sum composition passed for all three representations;
  a separately valid exponential permutation with unchanged Z cannot substitute.
- Ledger: two lookup identities and unsquared reductions remain separate.
  Range/A3 numerator9a+7bp+7bz and sum A1 numerator a match the first matrix
  proofs. Draws are4a+3bp+3bz ZeroWeight and5a+3bp+3bz Sumcheck. The full
  matrix and repository accounting gate remain pending.
- Bounds: expected K and E give both sides<=K*2^E<=2^28<p/2. Complete ranges
  precede whole-field lifts. The scalar bound rejects modular aliases even
  when they preserve the sumcheck statement. Bounds never use observed data.
- Padding/masks: expected caps set every masked/padded source to zero. All
  padded entries remain in the original consumer. The external scalar root
  always includes four byte leaves with exact zero extension. Zero never skips
  a range or the A1 final equation.
- Determinism: fixed source/byte/child order, canonical expected metadata and
  integer arithmetic. No table cache, float, challenge retry or timing choice.
- Parity: native CPU/SIMD/CUDA unchanged. The10000-case independent NumPy sum/
  byte corpus passed, including1157 zero sums and all byte widths. Both proof
  fields/repetitions and the full16384-row proof still require completion.
- Cost: O(N) byte views, two complete ranges/lookups and one A1 charge
  c_x/c_sc/c_lu/T_misc. No measured constant, benchmark or weight-pass change.
- Verifier: expected dimensions and strict proof keys/field encodings govern
  every payload. Complete verification rejects supplied receipt authority.
  Native no_std is unchanged; revealing roots are not a private PCS admission.
- Glossary/history: existing source/range/claim vocabulary and append-only
  Draft/accounting entries. Original E5/E7 criteria remain blocked. No native
  NC-0503, profile or complete attention credit is claimed.
