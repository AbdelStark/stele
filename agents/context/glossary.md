# Glossary (use these words exactly)

- **claim** — `(tensor, point, value)`: an assertion `f̃(point) = value`.
- **reduction** — a sub-protocol that consumes claims and emits claims (never "gadget", never "component").
- **stage** — one stacked reduction executed across all layers/heads in one transcript segment.
- **stacked tensor** — a per-layer (or per-head) tensor viewed as one tensor with the layer/head index as leading hypercube variables.
- **cut** — a committed tensor that breaks sequential dependency; the residual stream `R_ℓ` and the explicitly scoped Requant advice cut of RFC-0023 and its RFC-0024 embedded-input mode (RFC-0007 A3/A4).
- **virtual tensor** — any tensor never committed; its claims are reduced to other tensors.
- **weight pass** — one streaming read of a stacked weight type to compute `B[ℓ,k] = W̃(ℓ,k,r_j)`.
- **fused opening** — PCS opening whose row vector `u` is the retained row the weight pass built `B` from: `u = B` under the signed embedding, `u = B + 2^(w−1)` under offset (RFC-0007 A1).
- **functional opening** — PCS proof of `aᵀ M b` for verifier-computable `a, b`.
- **passport** — the registered artefact set of a model (RFC-0011).
- **CQIS** — the canonical integer semantics; `cqis_id` identifies version + config.
- **bound certificate** — static overflow-freedom statement per reduction instance.
- **range discipline** — every committed element's range is enforced exactly once by a dominating lookup.
- **attained** — a prover-chosen extremum (max, scale) proven to be realised by a committed index.
- **profile** — `standard` or `treaty` parameter set (RFC-0002 §8).
- **development profile** — the RFC-0026 parameter set: M31/QM31, no ZK, conjectural PCS, FS unproven. It is not an RFC-0002 §8 profile and claims no security level.
- **ledger** — the soundness error accounting (RFC-0012 §4) or the bench result file (RFC-0018).
- **control** — a negative test that must be rejected for a stated reason.
- **digest gate** — CI check that proofs on fixed inputs are byte-identical to recorded digests.
- **parity gate** — CI check that CUDA and CPU produce identical bytes.
- **plan** — `plan.json`, the canonical lowering of a model config to stages, derived identically by prover and verifier.
- **M31/CM31/QM31/OM31** — base field and its degree-2/4/8 extensions. **K** — the challenge field in force.
- source context: the verifier-owned field, code, dimensions, layout, policy, identity and root of RFC-0010 A9.
- registration certificate: the full proximity proof verified for one source context.
- verified certificate: an opaque handle created only by complete registration-certificate verification; it retains the original conditional loss record.
- source version: the field-source byte format of RFC-0010 A9/A3; version 1 is a Circle source, version 2 a v2 expander source.
- query policy: the verifier-derived rule fixing a source's certificate and opening query counts q_c, q_o (Policy 1, RFC-0010 A3); it is not a profile parameter set.
- message embedding: the injective map from one original source value to its one committed M31 message element, signed or offset (RFC-0010 A6).
- shard exponent: s in a source context's layout byte; the source has 2^s row shards of consecutive rows, fixed by the plan and never by the device count (RFC-0010 A13); not the split index s of RFC-0007 A1 item 2.
- child root: the root of one row shard's byte-column tree, in shard-index order (RFC-0010 A13).
- root of roots: the RFC-0012 A3 kind-2 root over a source's ordered child roots; it is that source's expected root when s>=1 (RFC-0010 A13).
Forbidden synonyms: "circuit" (say reduction/claim graph), "trace" (nothing is traced), "gadget", "constraint system",
"prover-side randomness".

- **byte-range handle** — opaque completed all-one range_8 A5 result for one exact original certificate, borrowing its genuine owners and retaining its conditional event/lifetime obligations (RFC-0024 §1.1).
- **point-equality record** — PointEqualityRecord for the fixed-polynomial SZ loss at the actual A3 tail; it introduces no new challenge or executed sumcheck (RFC-0024 §5).
- **grouped row** — an activation row converted under Policy mode 2, with one dynamic group scale per g consecutive features (RFC-0004 A15). This is distinct from a grouped lookup (RFC-0008 A5) and from GQA key/value groups (Shape.groups).
- **group scale** — s_k = ceil(max|X|/127) over group k of a grouped row; indexed by the high log2(n/g) row-index bits (RFC-0004 A15).
- **fold** — the magnitude F = s_k*|q_i| of a grouped-row code times its group scale, joined to its digits in byte columns (RFC-0004 A15 schema 23).
- **digit row** — row t of the signed radix-256 digits of the folded values; each is one field matmul input, extending the matmul row index (RFC-0004 A15, RFC-0007 A6).
- **column** — a committed, weight or public vector of 2^n integers with a declared signed/unsigned width of at most 30 bits (RFC-0026 §2.1).
- **commitment group** — witness columns of one length committed as one PCS source; a column claim is a source claim at a Boolean column index (RFC-0026 §2.3).
- **identity** — an RFC-0026 §3.2 relation: a sum of at most-3-factor products of columns with integer coefficients that is zero at every domain point over Z.
- **limb rule** — a value that would break the RFC-0026 §3.6 bound rule is held as range-checked radix limbs with explicit carries (RFC-0026 §3.5).
- **plain checker** — `stele_ir::relation::check`, the integer evaluation of every relation with no proof; the specification oracle for RFC-0026 modules.
- **advice** — a column whose values are not a fixed polynomial function of other columns: the output of rounding, clamping, selection, digit splitting or a table. Advice is committed (RFC-0028 §1.2, Draft).
- **commit rule** — commit exactly the advice; everything else on the witness side is a virtual column (RFC-0028 §1.2, Draft).
- **virtual column** — a relation-IR column defined as a linear map, a pointwise product or a two-factor contraction of other columns; claims on it are reduced, never opened (RFC-0028 §2.1, Draft). The relation-IR form of a virtual tensor.
- **segment** — commitment groups committed, proved and dropped together, in plan order (RFC-0028 §2.3, Draft).
- **carried column** — a witness column of one segment that the next segment may read; the residual stream at a segment boundary.
- **sumcheck fold** — binding one variable of a dense table to a challenge (RFC-0006 A1). Write it in full wherever the grouped-row fold of RFC-0004 A15 could be meant.
- **partial evaluation** — the table of one matmul operand with its free variables fixed at a point; the weight-side one is the weight pass.
- **row combination** — `u = aᵀM` for a committed matrix `M` (RFC-0010 §2); in a fused opening it is the weight pass.
- **fresh mode**, **certified mode** — openings of per-proof sources at a transcript-random point, and of registered model sources against their certificate (RFC-0029 §1.3, Draft).
- **tier** — the rigour a capability has passed: T0 development, T1 `standard`, T2 `treaty` (RFC-0027 §2).
- **ladder**, **rung** — the fixed workloads L0 to L6 that progress is measured on (RFC-0027 §3).
- **scoreboard** — `bench/scoreboard.md`, generated from the ledgers; one row per rung and profile.
- **lane** — a set of crates with one owner role and one open line of work, a change or a stack that merges in order (RFC-0027 §5).
- **gate** — a milestone M0 to M7, met when its ledgers and controls exist (RFC-0027 §4). Also a CI check; context decides.
- **round-by-round error**, **λ** — the largest probability that one round's challenge rescues a false claim; a proof has λ bits when it is at most 2^-λ (RFC-0030, Draft).
- **cells per token**, **lookups per token** — committed cells and lookup positions divided by positions in the window; the protocol-efficiency pair reported by the accounting tool (task E22-01).
- **hiding source** — a version-3 Circle source whose message is `[X | Rm ; S0 | S1]`: the data `X`, a mask half per data row and as many mask rows, with a salt in each leaf (RFC-0013 A2, RFC-0010 A14).
- **mask half** — the upper half of a hiding-source message row, uniform values that hide up to `C − 1` queried positions (RFC-0013 A2).
- **mask rows** — the lower half of a hiding-source message, uniform rows that hide the certificate and opening rows (RFC-0013 A2).
- **masked sumcheck** — an RFC-0006 A1 sumcheck run on `f + α·g` with a uniform sum-of-univariates mask `g`, ending with the mask obligation `(ρ, g(ρ))` (RFC-0013 A2).
